# 東京都内 公契約条例マップ（デモ版）

地図の自治体をクリックすると、公契約条例の対象契約・労働報酬下限額・条例の内容などが表示されるページです。

## ファイル

- `index.html` … ページ本体。地図とデータがすべて入っているので、このファイル1つで動きます。
- `data/koukeiyaku.json` … Excelの「一覧」シートから取り出したデータ（確認・更新用）。

## GitHub Pagesで公開する手順

1. GitHubで新しいリポジトリを作る（例：`koukeiyaku-map`）。
2. このフォルダの中身（`index.html` など）をアップロードする。
   リポジトリ画面の「Add file」→「Upload files」でドラッグ＆ドロップできます。
3. リポジトリの「Settings」→「Pages」を開く。
4. 「Branch」で `main` と `/ (root)` を選んで「Save」。
5. 数分後、`https://<ユーザー名>.github.io/koukeiyaku-map/` で見られるようになります。

## データの出典

- 公契約条例 制定自治体一覧（2026年度、Excel）… 24自治体の条例制定日・対象契約・労働報酬下限額など
- 人口 … 同Excelの「人口」シート（2026年4月1日現在）
- 板橋区 … 2026年10月14日の区議会本会議での可決内容
- 練馬区 … 練馬区公式ページ（公契約条例検討委員会の設置）
- 東大和市・葛飾区・東村山市 … 東京地評の制定状況マップ

内容は各自治体の公表資料で確認してください。
